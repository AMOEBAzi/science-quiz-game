# 🔬 과학 퀴즈 게임 (Science Quiz Game)

## 📖 프로젝트 개요

**과학 퀴즈 게임**은 Python으로 구현된 터미널 기반 대화형 퀴즈 애플리케이션입니다.
사용자는 과학 주제의 퀴즈를 풀고, 새로운 퀴즈를 추가할 수 있으며, 점수를 기록하고 관리할 수 있습니다.
프로그램을 종료하고 다시 실행해도 데이터가 JSON 파일로 저장되어 유지됩니다.

### 🎯 주요 특징
- ✅ 터미널 기반 메뉴 시스템
- ✅ **객체 지향 프로그래밍** (Quiz, QuizGame 클래스) - 기능 확장성과 유지보수 용이성 향상
- ✅ **JSON 파일을 통한 데이터 영속성** - 텍스트 기반 포맷으로 휴먼 리더블하고 구조화된 데이터 관리
- ✅ 최고 점수 자동 기록
- ✅ 강건한 입력 검증 및 오류 처리 (숫자/범위/빈값 검증)
- ✅ Ctrl+C 안전 종료 처리 (자동 저장)
- ✅ 기본 퀴즈 **10개 포함** (5개 기본 + 5개 추가)

## 🤔 퀴즈 주제 선정 이유

### 주제: **과학 (Science)**

**선택 이유:**
1. **교육적 가치**: 일반인도 쉽게 이해할 수 있는 과학 지식 학습
2. **다양성**: 물리학, 화학, 생물학, 우주론 등 여러 분야를 포함
3. **확장성**: 사용자가 자신의 관심 분야에 맞춰 퀴즈를 추가 가능
4. **실용성**: 프로그래밍과 별개로, 일상 생활에서 유용한 지식 습득

**기본 퀴즈 주제:**
- 🌞 물리학: 빛의 속도, 태양, 지구의 자전
- ⚛️ 화학: 분자 구조, 원소
- 🧬 생물학: 세포, DNA, 뇌
- 🌌 우주학: 빅뱅, 별, 행성

## 🚀 실행 방법

### 필수 조건
- Python 3.10 이상
- pip (파이썬 패키지 관리자) - 표준 라이브러리만 사용하므로 불필요

### 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/AMOEBAzi/science-quiz-game.git
cd science-quiz-game

# 프로그램 실행
python main.py
```

### 메뉴 사용법

프로그램 실행 후 다음 메뉴가 표시됩니다:

```
========================================
    🎯 나만의 과학 퀴즈 게임 🎯
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택:
```

**각 메뉴 설명:**
- **1번 (퀴즈 풀기)**: 저장된 모든 퀴즈를 순서대로 풀고 점수 확인
- **2번 (퀴즈 추가)**: 새로운 퀴즈 등록 (문제, 선택지 4개, 정답)
- **3번 (퀴즈 목록)**: 등록된 모든 퀴즈 제목 확인
- **4번 (점수 확인)**: 최고 점수 및 성적 조회
- **5번 (종료)**: 프로그램 종료 (자동 저장)

## 📁 파일 구조

```
science-quiz-game/
├── main.py              # 프로그램 진입점
├── quiz.py              # Quiz 클래스 정의
├── game.py              # QuizGame 클래스 정의
├── quiz_data.py         # 추가 퀴즈 데이터
├── state.json           # 퀴즈 데이터 및 점수 저장 파일 (자동 생성)
├── .gitignore           # Git 추적 제외 파일
└── README.md            # 이 파일
```

### 파일 설명

**main.py**
- 프로그램의 진입점
- QuizGame 객체를 생성하고 `run()` 메서드 실행

**quiz.py**
- `Quiz` 클래스: 개별 퀴즈를 표현
- 속성: `question` (문제), `choices` (선택지), `answer` (정답)
- 메서드: `display()` (화면 출력), `check_answer()` (정답 확인), `to_dict()` / `from_dict()` (JSON 변환)

**game.py**
- `QuizGame` 클래스: 게임 전체를 관리
- 메서드:
  - `load_data()`: JSON 파일에서 데이터 로드
  - `save_data()`: 데이터를 JSON 파일에 저장
  - `display_menu()`: 메인 메뉴 출력
  - `play_quiz()`: 퀴즈 풀기 기능
  - `add_quiz()`: 퀴즈 추가
  - `show_quizzes()`: 퀴즈 목록 표시
  - `show_score()`: 점수 표시
  - `run()`: 메인 루프

**quiz_data.py**
- 기본 퀴즈 외의 추가 과학 퀴즈 5개 정의
- `get_additional_quizzes()` 함수로 퀴즈 목록 반환

### 입력 검증 및 데이터 IO 담당 함수/메서드 매핑

#### 입력 검증 담당
| 메서드 | 파일 | 검증 내용 | 오류 처리 |
|--------|------|---------|---------|
| `get_menu_choice()` | game.py | 1-5 범위 숫자 | 빈 입력, 숫자 아님, 범위 초과 |
| `play_quiz()` - 정답 입력 | game.py | 1-4 범위 숫자 | 빈 입력, 숫자 아님, 범위 초과 |
| `add_quiz()` - 정답 입력 | game.py | 1-4 범위 숫자 | 빈 입력, 숫자 아님, 범위 초과 |
| `check_answer()` | quiz.py | 정답 비교 (정수) | 범위 초과 시 False 반환 |

#### 데이터 IO 담당
| 메서드 | 파일 | 역할 | 저장 시점 |
|--------|------|------|---------|
| `load_data()` | game.py | JSON 읽기, 복구 | 프로그램 시작 |
| `save_data()` | game.py | JSON 쓰기 | 최고 점수 갱신, 퀴즈 추가, 종료 시 |
| `to_dict()` | quiz.py | Quiz → dict | save_data 내부 |
| `from_dict()` | quiz.py | dict → Quiz | load_data 내부 |

**참고**: 모든 IO 작업은 try/except로 보호됨. JSON 손상 시 기본 데이터로 자동 복구.

## 💾 데이터 파일 설명 (state.json)

### 위치
프로젝트 루트 디렉토리: `state.json`

### 역할
- 사용자가 추가한 퀴즈 데이터 저장
- 최고 점수 기록
- 프로그램 재실행 시 데이터 복구

### 파일 형식 및 스키마

```json
{
  "quizzes": [
    {
      "question": "태양이 주로 구성된 원소는?",
      "choices": ["산소", "수소", "헬륨", "질소"],
      "answer": 2
    },
    {
      "question": "사용자 정의 퀴즈",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ],
  "best_score": 80
}
```

### 필드 설명

| 필드 | 자료형 | 설명 |
|------|--------|------|
| `quizzes` | list | Quiz 객체 리스트 (JSON) |
| `quizzes[].question` | str | 퀴즈 문제 |
| `quizzes[].choices` | list | 선택지 4개 배열 |
| `quizzes[].answer` | int | 정답 번호 (1-4) |
| `best_score` | int | 최고 점수 (0-100) |

### 인코딩
- **UTF-8**: 한글을 포함한 모든 문자 지원

### JSON 선택 이유
| 항목 | 이유 |
|------|------|
| **가독성** | 텍스트 형식으로 사람이 쉽게 이해 가능 |
| **구조화** | 중첩된 객체/배열로 복잡한 데이터 표현 |
| **표준성** | 웹/API 표준 포맷으로 활용 기초 제공 |
| **경량성** | 소규모 프로젝트에 최적 (DB 불필요) |

### 한계 및 대안
**JSON의 한계:**
- 대용량 데이터 (100만+ 퀴즈): 메모리 부담 증가
- 동시 쓰기: 파일 잠금 필요 (현재 미구현)
- 빈번한 업데이트: 전체 파일 재작성 필요

**대안:**
- **SQLite**: 소규모 관계형 DB, 파일 기반 (다음 단계)
- **MongoDB**: 확장성 필요 시 (서버 구성 필요)

### 자동 생성 및 복구
- **첫 실행**: 파일이 없으면 기본 퀴즈 10개로 자동 생성
- **손상된 파일**: JSON 형식 오류 시 기본 데이터로 복구 후 알림
- **매 실행 후**: 자동으로 최신 데이터 저장
- **백업 제안**: `state.json.bak` 자동 생성 검토 (v2.0)

| `Docs` | 문서 수정 | `Docs: README 업데이트` |
| `Refactor` | 코드 리팩토링 (기능 동일) | `Refactor: load_data 메서드 정리` |
| `Chore` | 빌드, 의존성, 도구 | `Chore: .gitignore 파일 추가` |
| `Test` | 테스트 추가/수정 | `Test: 입력 검증 테스트 추가` |

### 커밋 단위
- **한 커밋 = 한 작업**: 하나의 기능/버그 수정만 포함
- **명확한 이유**: 커밋 메시지에 "왜" 변경했는지 기술
- **테스트 가능**: 각 커밋 단위로 프로그램이 실행 가능해야 함

### 예시
```
Feat: Quiz 클래스 구현 - 개별 퀴즈 표현 및 정답 확인 기능

- Quiz 클래스 정의 (question, choices, answer 속성)
- display() 메서드로 퀴즈 화면 출력
- check_answer() 메서드로 정답 판정
- to_dict()/from_dict() 메서드로 JSON 변환 지원
```

## 📊 복구 정책 및 우선순위

### 파일 로드 우선순위
1. **state.json 존재 확인** → 2번으로
2. **JSON 형식 검증** → 3번으로
3. **필드 완전성 검증** → 4번으로
4. **손상 시 기본값 복구** (사용자 알림)

### 손상 처리 흐름
```
손상된 파일 감지
    ↓
exception 캐치 (JSONDecodeError, KeyError)
    ↓
기본 퀴즈 10개로 초기화
    ↓
경고 메시지 출력
    ↓
복구된 state.json 저장
```
